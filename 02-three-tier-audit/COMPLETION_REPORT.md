## Project Objective

Understand and demonstrate the three-tier architecture of data persistence when working with AI platforms:
- **Tier 1:** Working/session context within the AI platform
- **Tier 2:** Platform-stored outputs and files
- **Tier 3:** User-exported outputs existing independently

The core question: **If vendor access disappeared, what would you actually lose?**

## Task Performed

**Description:** Generate an educational study document about the three states of matter using Claude.ai and export it to local storage

**Platform Used:** Claude.ai (web interface)

**Execution Summary:**
1. Opened a new chat on Claude.ai (no prior projects, memory, or custom instructions)
2. Requested: "Create a study document about 'The Three States of Matter'"
3. Claude.ai generated comprehensive educational content
4. Document included definitions, characteristics, examples, and comparison table
5. Content was exported as `three-states-of-matter.md` (Markdown format)
6. File was downloaded to the local Downloads folder
7. File now exists independently outside Claude.ai

## State/Context Layer Identification

### Tier 1: Working Context
- **Where:** Claude.ai conversation interface
- **Type:** Session-based, temporary
- **Persistence:** Only during active chat
- **Access:** Claude.ai required

### Tier 2: Platform Storage
- **Where:** Claude.ai's internal systems (if stored)
- **Type:** Platform-based output storage
- **Persistence:** While account is active
- **Access:** Claude.ai required

### Tier 3: Local Export
- **Where:** Local file system (Downloads folder)
- **Type:** Independent file storage
- **Persistence:** Permanent (file remains even if platform changes)
- **Access:** No platform required

**Context Used:** Only Claude.ai conversation/session context; no projects, memory, or external integrations

## Vendor-Loss Implications

### Scenario: Claude.ai Account/Vendor Access Becomes Unavailable

**Would Be Lost:**
- Access to the Claude.ai conversation where the document was generated
- The session history and context
- Any copy of the content that existed only within Claude.ai's platform

**Would Still Exist:**
- The downloaded `three-states-of-matter.md` file confirmed in the local Downloads folder
- The ability to read, edit, and use the file on the local computer

**Key Observation:** The locally downloaded file would remain accessible on the computer, independent of Claude.ai's platform access or availability.

4. **No Account Deletion Test:** Did not test what happens if the account is permanently deleted
